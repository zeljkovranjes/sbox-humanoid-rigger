Run the self-contained lumbar skinning regressions with .NET 10:

```powershell
dotnet run --project tests/TorsoWeights/TorsoWeights.csproj -c Release
```

The fixtures exercise asymmetric leg and collarbone influence on the spine, scale independence, hip and shoulder transitions, accessories, partial rigs, normalization, idempotence, and validation rollback. They require no external character assets or editor installation.
